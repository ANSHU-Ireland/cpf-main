## Synthesis decisions

- A stable role-aware shell and object context are used across operational interfaces.
- Task queues and filterable tables are used for high-volume administrative work.
- Guided steps are used only for consequential or multi-stage creation flows.
- Reviewer work uses the selected two-pane evidence/criterion layout.
- AI observations are deliberately secondary and hidden until independent human evidence review.
- No visual pattern introduces an AI score, candidate ranking, integrity verdict or progression recommendation.
- Candidate runtime favours orientation, server time, explicit save state and recoverability over dashboard density.
