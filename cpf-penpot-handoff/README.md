# CPF Option 2 — Penpot-ready comprehensive wireframe

This package contains 125 complete interface specifications covering 244 OpenAPI operations, 362 requirements and 139 parsed PostgreSQL tables.

## Start here

1. Read `developer-handoff.md` for authority, state, accessibility and implementation contracts.
2. Import all SVGs from `boards/` into Penpot for journey boards.
3. Use `interfaces/` when the team wants one importable 1440 × 1024 screen at a time.
4. Use `coverage/endpoint_coverage.csv`, `requirement_coverage.csv` and `schema_coverage.csv` as acceptance gates.
5. Open `index.html` for a searchable local catalogue.

## Visual direction

Option 2 uses a warm, humane enterprise system: pale stone shell, white task surfaces, charcoal text, restrained cobalt actions, sage success, amber caution, 8–10 px radii and almost no shadow. The reviewer workspace uses a wide evidence pane and a focused one-criterion scorecard. AI observations require a deliberate secondary reveal after independent human review.

## Source authority

The attached PRD, TRD, traceability CSV, OpenAPI YAML, SQL baseline and schema dictionary are copied into `source-manifest.json` by hash reference only; this package does not mutate the supplied files.
